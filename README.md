# DSC212 Karate Club assignment submission
This is my submission for a course assignment on community detection using modularity, on the Zachary Karate Club dataset, for the year 2026, the DSC212 course on _Mathematical Foundations for Data Science_ at IISER Thiruvanthapuram. It is an iPyNB with visualisations. An added section on my AI use regarding this assignment has also been added for clarity.

On a sidenote, this was the most fun I had in writing an assignment in my time in this institute so far.
